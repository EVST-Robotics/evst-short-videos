# EVST Short Videos — Public CDN Mirror

Public-readable mirror of EVST's short-form marketing videos.
Used as a `raw.githubusercontent.com` URL source for automated publishing pipelines (Douyin, Kuaishou via aitoearn.cn, and other platforms requiring a public `videoUrl`).

## Layout

```
<YYYY-M-D>/
  <keyword-application>/
    en/  English versions (overseas: YouTube, LinkedIn, Facebook, Instagram, X)
    cn/  Chinese versions (domestic: Douyin, Kuaishou, WeChat Channels)
    ru/  Russian versions (VK)
```

## Raw URL format

```
https://raw.githubusercontent.com/EVST-Robotics/evst-short-videos/main/<path>
```

Example:
`https://raw.githubusercontent.com/EVST-Robotics/evst-short-videos/main/2026-5-11/industrial-robot-palletizing/en/palletizing_en.mp4`

## Notes

- Files are public. Do not store source materials, internal drafts, or anything with customer-identifiable content.
- Naming convention: lowercase, hyphens for spaces.
- Keep individual files under 50 MB (GitHub soft limit; hard limit 100 MB).
